# 📸 Web Tabanlı Albüm ve Kayıt Sistemi (PHP & MySQL)

Bu proje, Bootstrap 5 kullanılarak geliştirilmiş, responsive (mobil uyumlu) bir web uygulamasıdır. 

## 🚀 Proje İçeriği
1. **Albüm Yönetim Sistemi (`index.php`):** İnternet üzerindeki görsellerin URL'leri ve açıklamaları ile eklendiği, listelendiği, güncellenebildiği ve silinebildiği (CRUD) kart tabanlı bir galeri.
2. **Kullanıcı Kayıt Sistemi (`register.php`):** Sisteme yeni kullanıcıların bilgilerini girerek kayıt olabildiği ve kayıtlı kullanıcıların anlık olarak listelendiği form yapısı.

## 🛠️ Kullanılan Teknolojiler
* **Back-end:** PHP
* **Veritabanı:** MySQL (PDO Kullanılarak)
* **Front-end:** HTML5, CSS3, Bootstrap 5

## ⚙️ Kurulum ve Çalıştırma
1. Proje dosyalarını WampServer veya XAMPP'in `www` / `htdocs` klasörüne kopyalayın.
2. phpMyAdmin üzerinden `odev4_db` adında boş bir veritabanı oluşturun.
3. Proje klasöründeki `odev4_db.sql` dosyasını bu veritabanının içine "İçe Aktar (Import)" diyerek yükleyin.
4. Tarayıcınızdan `http://localhost/odev4/index.php` adresine giderek projeyi başlatın.
